# Export your calendar to another calendar app

This guide covers downloading a copy of your calendar's events as one file and opening it in another calendar app: Google Calendar, Apple Calendar, or Outlook. The file is an `.ics` file, the standard calendar format those apps all read.

## What an export is for

An export gives you a copy of your events to keep somewhere else. A neighborhood association can put its season's events in the board's shared Google Calendar, and a venue can keep a list of the dates and details it published before a big change to its program.

An export is a snapshot, not a connection. Nothing keeps the file in step with Pavillion, so edits, new events, and cancellations you make afterward don't reach it. To keep other people in step with your calendar, give them your [public URL](./public-url), or, if they run a Pavillion calendar of their own, let them [follow yours](./follow-and-repost). The file is meant for other calendar apps, not for moving events into another Pavillion calendar: importing it there shows dates you cancelled as going ahead.

## Find Export

Open **Settings → Calendar → Export**, and check which calendar you're exporting. The calendar's name shows the one you're working on; click it to switch. On a computer it sits above the screen title; on a phone it is the title of the **Calendar** screen.

Only the calendar's owner sees **Export**. Your editors can add and change events, but they can't download the calendar.

Choose a language if the page asks for one, then click <Btn>Download</Btn>. The file is saved to your downloads. If your calendar has no events of its own yet, no file is saved, and the page says *This calendar has no events of its own yet, so there is nothing to download.*

## What the file holds, and what it leaves out

The file holds every event your calendar publishes, past and future. Each event comes with:

- Its **title** and **description**, in the language you chose.
- Its **Accessibility Information**, at the end of the description under an *Accessibility* heading.
- Its **dates and times**. A recurring event comes out as a recurring event, so the other app keeps repeating it.
- Its **place**, its **categories**, and a link to the event's page on your public calendar.

A date you cancelled with **Hide from public** on is left out of the file. A date shown on your public page as **Cancelled**, including a one-time event you cancelled, is in the file with its usual title, marked cancelled. How the other app displays a cancelled date is up to that app. [Post a recurring event](./recurring-events#cancel-a-single-occurrence) covers the difference between the two.

The file leaves out events you reposted from other calendars, and from your own events it leaves out the image, the **External Link**, and which series an event belongs to.

## Choose a language

Each file holds one language. The **Language** list offers the languages your calendar and its events are written in, and starts on the language you use Pavillion in, if your calendar has it, or on the first language in the list if it doesn't. A calendar written in one language shows no list at all.

An event with no text in the language you chose comes out in another language it is written in.

The language is part of the filename: your calendar's URL handle, then the language code, as in `riverbend-folk-en.ics` and `riverbend-folk-es.ics`. To get a second language, choose it and click <Btn>Download</Btn> again.

::: tip <Lightbulb /> A note on which language to pick.
Pick the language of the people who will read the copy. If the copy is for a Spanish-speaking partner organization, download the Spanish file. If two groups each want a copy, download a file for each rather than sending one group text it can't read.
:::

## Bring the file into another calendar app

Each app asks which of your calendars the events go into. Create a new, empty calendar in the other app first and import into that one. Your events then stay separate from your personal appointments, and when you want a fresher copy you can delete that calendar and import a new file.

**Google Calendar** imports a file on a computer only. The Google Calendar phone app has no import.

1. Open Google Calendar in a web browser on a computer.
2. Open **Settings**, then **Import & export**.
3. Choose the file, choose the calendar to add the events to, and import.

On an iPhone, open the file instead, as in the Apple Calendar steps below. The phone offers to add the events to a calendar on the phone, which can be a Google calendar signed in on it.

**Apple Calendar on a Mac:**

1. Open Calendar.
2. Choose **File**, then **Import**, and pick the file.
3. Choose the calendar to add the events to.

**Apple Calendar on an iPhone or iPad:** open the file from Files, from Safari's downloads, or from an email it was attached to. The phone offers to add the events and asks which calendar they go into. If you download the file in Safari on the phone, Safari may make that offer as soon as the download finishes. That's expected, and it's the same import.

**Outlook:** the steps depend on which Outlook you use.

- **Outlook on the web and the new Outlook for Windows:** open the calendar, choose **Add calendar**, then **Upload from file**, and pick the file and the calendar to add it to.
- **Classic Outlook for Windows:** choose **File**, then **Open & Export**, then **Import/Export**, and import the file.
