# Translating Pavillion

> Status: stub. Full guide coming before launch.

Planned scope:

- Who this is for: translators who know the language well, whether or not they've used git before
- Adding a new language versus improving one that already exists
- Where translation files live and how they're organized by namespace
- Seeing your translation in the running application before you submit it
- Strings that are hard to translate well: plurals, placeholders, and text that depends on context
- What the guides themselves don't cover yet: translating the documentation site

Until this guide is written, the [internationalization guide](https://github.com/stephenhoward/pavillion/blob/main/docs/internationalization.md) on GitHub covers registering a language and where translation files live.
