# Writing documentation

> Status: stub. Full guide coming before launch.

Planned scope:

- Who this is for: calendar owners, administrators and developers who found a guide confusing, wrong or missing

- Previewing a change locally before you open a pull request
- The voice the guides are written in: who the reader is, leading with the conclusion, naming limits honestly

Until this guide is written, the [contributing guide](https://github.com/stephenhoward/pavillion/blob/main/docs/CONTRIBUTING.md) on GitHub covers the pull-request workflow.
